# Installation checklist

1. Publish the Wix adoption page and identify the HTML ID of its dog-list container.
2. In Wix, open **Settings → Custom Code → Add Custom Code**.
3. Paste the snippet from `README.md`.
4. Replace `ACCOUNT` with the ShelterManager account number.
5. Replace `asm3-adoptables` if the Wix container uses a different ID.
6. Apply the code only to the adoption page, place it in the head, and publish.
7. Open the published English, Spanish, and German pages and check the browser console for errors.

Never commit passwords, API keys, private animal information, or ShelterManager login credentials to this public repository.
